# Privacy

*Français ci-dessous.*

PDF Manager is designed so that your documents stay on your device.

- **Processing is local.** Opening, editing, OCR, compression and conversion
  run on your computer (desktop app) or inside your browser tab (web
  edition). Documents, images, signatures, recognised text and results are
  never uploaded.
- **No account, no analytics, no advertising, no tracking, no crash
  reporting, no automatic update checks.**
- **What is stored:** your interface language. The web edition also keeps a
  copy of the application files, and — only if you ask — the OCR language
  packs, in your browser's storage so it can work offline. The *Offline use* button at the
  bottom of the page → *Remove offline data* deletes them.
- **What is not stored:** your files or results. The desktop app keeps
  Chromium's normal technical data (for example a graphics cache) in
  `%APPDATA%\PDF Manager`; it contains no document content. Your operating
  system may still write memory to its page file; no secure erasure is
  claimed.
- **Network use:** the desktop app blocks all network requests. Clicking the
  author or project link opens it in your normal browser. The web edition
  downloads its own files (and OCR packs when used) from the site that
  hosts it; that host (GitHub Pages) may keep standard server logs such as
  IP addresses, under GitHub's own privacy statement.
- **Saved files** go only where you choose.

Questions: see `SUPPORT.md`.

## Confidentialité

PDF Manager est conçu pour que vos documents restent sur votre appareil.

- **Traitement local.** Ouverture, modification, OCR, compression et
  conversion se font sur votre ordinateur (application de bureau) ou dans
  l'onglet de votre navigateur (version web). Documents, images,
  signatures, texte reconnu et résultats ne sont jamais envoyés.
- **Ni compte, ni statistiques, ni publicité, ni pistage, ni rapports
  d'erreur, ni vérification automatique des mises à jour.**
- **Ce qui est conservé :** la langue de l'interface. La version web garde
  aussi une copie des fichiers de l'application et — seulement si vous le
  demandez — les packs de langue OCR, pour fonctionner hors ligne ; le bouton *Hors ligne* en bas de
  la page → *Supprimer les données hors ligne* les efface.
- **Ce qui n'est pas conservé :** vos fichiers et résultats. L'application
  de bureau conserve les données techniques habituelles de Chromium (par
  exemple un cache graphique) dans `%APPDATA%\PDF Manager`, sans contenu de
  document. Le système peut écrire la mémoire dans son fichier d'échange ;
  aucun effacement sécurisé n'est garanti.
- **Réseau :** l'application de bureau bloque toute requête réseau. Les
  liens vers l'auteur ou le projet s'ouvrent dans votre navigateur habituel.
  La version web télécharge ses propres fichiers (et les packs OCR si vous
  les utilisez) depuis le site qui l'héberge ; cet hébergeur (GitHub Pages)
  peut tenir des journaux serveur habituels (adresse IP, etc.) selon sa
  propre politique.
- **Les fichiers enregistrés** vont uniquement là où vous le choisissez.
