# Support

- **Questions, problems, ideas:** open an issue
  (https://github.com/bakodramane/pdf_manager/issues) using a template.
  Questions in French are welcome — les questions en français sont les
  bienvenues.
- **Security issues:** see `SECURITY.md` (private reporting, not public
  issues).
- **Before reporting:** check the edition and version (*Credits*), try the
  latest release, and remove personal data from any sample file.
- **IT departments:** the Windows installer is per-user and never asks for
  administrator rights, but it does not override your organisation's
  application-control policies (AppLocker, WDAC, SmartScreen). Prefer signed
  releases where policies require them, or use the web edition.

Support is provided by a volunteer maintainer on a best-effort basis; no
response time is promised.
